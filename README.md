# NULLWAVE / Nexus

A front-end-only **simulation** of a futuristic shielded settlement network styled after Solana.
Everything (hashes, proofs, balances, transactions) is randomly generated. No real blockchain, cryptography or funds are involved.

## Run locally
Open `index.html` in a browser.

## Deploy on Railway
Deploy from this GitHub repo. The included `Dockerfile` serves `index.html` with Caddy on `$PORT`.
